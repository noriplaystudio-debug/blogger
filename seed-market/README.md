## v5.2 무료 나눔의 금액 의견과 기준 참고 통계

- 나눔 원문에서 열람료·추가 사용료 의견과 참여자가 판단한 완성도·사유를 남깁니다. 가격은 미리 채우지 않으며 빈칸과 무료 의견(0원)을 구분합니다.
- 계정당 현재 자료의 의견 한 개를 수정·철회할 수 있습니다. 작성자·운영자 참여를 막고 다른 자료/질문 버전·철회·운영 제외 의견을 현재 통계와 섞지 않습니다.
- 글별 중앙값·가운데 50%·금액대 분포·참여 수를 제공하며 이름·회원 ID를 공개하지 않습니다.
- 운영자에게 분야·완성도·이용 조건·참여 역할·기간별 통계와 익명 CSV/JSON을 제공합니다. 글별 비중·표본·작성자 집중 조건을 충족할 때 검토용 수치를 표시하고 현재 권장액은 자동 변경하지 않습니다.
- [참여·보존·집계 기준과 한계](docs/COMMUNITY_PRICE_OPINIONS.md). 실제 거래가가 아닌 무료 공개 자료의 가정 의견입니다.

## v5.1 권장 가격과 아이디어 나눔터

- 판매자가 고른 기획 수준·자료 기준에 따른 초기 권장액을 판매 등록·최종 확인·공개 카드·상세·결제·운영 검토에서 안내합니다.
- 열람료 권장 상한 3,000 / 10,000 / 30,000원, 추가 사용료 참고 상한 30,000 / 100,000 / 300,000원입니다. 시장 감정가·품질 인증이 아니며 사용료의 10배 기준도 초기 운영 가설임을 표시합니다.
- 상한 초과 시 차액을 안내하지만 등록·구매를 차단하거나 판매가·수수료를 조정하지 않습니다. 새 주문에는 당시 참고 기준을 저장합니다.
- `/#sharing`에서 판매자·구매자가 무료 나눔 글을 등록하고 승인된 본문을 누구나 읽습니다. 이용 조건 선택, 내 글·수정·재검토·숨김과 운영자 검토, 검색·페이지 이동을 제공합니다.
- [가격 기준·무료 이용 조건·검증 범위](docs/PRICING_AND_SHARING.md), [프로젝트 변경 이력](docs/PROJECT_HISTORY.md).

## 먼저 알아둘 현재 범위

**실제 청구·환불·송금·법적 권리 이전이 없는 테스트입니다.**
실제 PG, 판매자 정산 및 세무 처리는 연결하지 않았습니다.
서약은 법률 검토 전 초안이며 추상적인 아이디어의 독점권을 자동 보장하지 않습니다.
등록 해시와 접근 기록은 내부 증빙이며 외부 공증이 아닙니다.

실제 소셜 키는 등록하지 않았고 실제 계정의 OAuth도 검증하지 않았습니다.
SDK 의존성 설치·Vinext 빌드·마이그레이션 생성·배포는 미완료입니다. 실제 브라우저의 standalone 테스트 흐름은 GitHub Actions에서 17/17단계가 통과했습니다. 현재 로컬 호스팅 ID는 원격에서 다른 계산기 프로젝트로 식별되어, 아이디어 마켓의 운영 배포로 확인되지 않았습니다.
서버 기능과 금액·권한·동시 요청 검증은 완료했습니다.

## 의존성 설치 없는 로컬 미리보기

Node.js 22.13 이상을 사용합니다. 표준 SQLite 및 파일 저장소로 서버 기능을 실행할 수 있습니다.

    npm run dev:standalone

http://127.0.0.1:4173 에서 엽니다.
가입·계정 화면에 판매자, 구매자 A/B, 운영자, 새 회원가입 테스트 계정이 표시됩니다.
운영자에서 등록 심사·수수료·신고·정산 및 인증 준비 상태를 확인합니다.
로컬 테스트 인증은 루프백에서만 동작하며 독립 소셜 인증 모드와 Sites 배포에는 포함하지 않습니다.

이전 Codex 실행에서는 로컬 서버의 바인딩이 EPERM으로 거부됐고 Chromium도 실행되지 않았습니다. v5.0.2 Work 보고서에서는 서버 시작이 통과했지만 브라우저는 준비되지 않았습니다. 브라우저 직접 조작은 미검증입니다.
환경 권한을 우회하는 별도 브라우저 경로는 사용하지 않았습니다.

## 실제 브라우저 검증 · QA-ENV-001

    npm run qa:prepare
    npm run qa:doctor
    npm run test:browser

고정 버전 Playwright·Chromium 준비 → 같은 환경에서 서버·브라우저·홈/메뉴 사전 진단 → 판매자·구매자·운영자와 모바일 전체 흐름 검사 순서입니다. 진단을 통과한 뒤 전체 검사로 진행합니다. 웹앱 전체 의존성 설치 없이 별도 QA 도구만 준비합니다.

격리된 테스트 DB·이미지를 사용하며 실제 실행의 스크린샷·trace·단계별 결과를 저장합니다. [GitHub Actions 39740383010](https://github.com/noriplaystudio-debug/blogger/actions/runs/39740383010)에서 doctor와 전체 흐름 17/17단계가 통과했습니다. 검사 도구의 버튼 선택·모바일 필터 순서와 한글 캡처 환경을 보완하고, 실제 스크린샷 17개·trace 7개를 확인했습니다. 테스트 결제와 모바일 에뮬레이션 범위이며 실제 OAuth·실제 결제·서비스 배포는 별도입니다. [검증 기록](docs/QA_ACTIONS_2026_10_22.md), [실행 안내](docs/BROWSER_TESTING.md)를 참고합니다.

v5.0.3은 설치 시작 시점부터 단계·중단 결과를 남기고 손상된 Chromium ZIP을 구분합니다. Chromium이 포함된 공식 이미지용 실행 경로도 추가했으나 현재 환경의 Docker 소켓 권한으로 실제 빌드·실행은 미검증입니다. [필요 실행 조건과 명령](docs/QA_CONTAINER.md)을 먼저 확인합니다. 제품 동작은 변경하지 않았습니다.

    npm run qa:tools-test

이 명령은 설치 기록 보존·강제 종료·아카이브 진단·증거 내보내기 검사를 실행하며 실제 브라우저 검사를 대신하지 않습니다.

## 인증 준비

    npm run auth:setup

Git에서 제외된 .env.local에 서버 인증 비밀값을 만들고, 출력에는 비밀값을 표시하지 않습니다.
공급자별 변수는 .env.example을 참고합니다. 실제 키는 나중에 서버 설정으로 등록합니다.
현재 Sites 인증을 유지하며 외부 소셜 로그인은 독립 Node 어댑터에서 활성화합니다.
전체 순서는 docs/AUTH_SETUP.md에 있습니다.

## 배포

Sites의 기존 프로젝트 ID, DB·BUCKET 바인딩과 sites() 빌드 연동을 유지합니다.
독립 Node 인증은 별도 운영 모드이며 영속 저장소와 HTTPS 프록시가 필요합니다.

네트워크가 가능한 환경에서 Sites 빌드를 준비하려면:

    npm install --prefer-offline --no-audit --no-fund
    npm run db:generate
    npm run build

소스 동기화와 Sites 게시 도구를 통해 검증한 커밋·빌드 결과를 게시해야 합니다.
로컬 실행용 SQL과 배포용 Drizzle 스키마를 제공하며, 생성된 배포 마이그레이션은 아직 없습니다.
idea_classification·idea_taxonomy·listing_requests·upload_cleanup·order_price_guidance·shared_ideas·share_value_sources·share_value_opinions 테이블을 포함해 배포 전에 마이그레이션을 준비해야 합니다.
과거 주문에 새 수수료를 임의로 계산해 붙이는 자동 백필은 하지 않습니다.

## 주요 파일

- ui/index.html, public/assets/: 방문자·판매자·운영자 화면.
- server/api.mjs: 회원, 자료, 열람권·사용권, 접근 검사.
- server/commerce.mjs, server/operations.mjs: 수수료, 정산, 검토·분쟁.
- server/schema.sql, server/operations.sql: 독립 로컬 실행용 초기 스키마.
- db/schema.ts: Sites 배포용 스키마.
- auth/: 공급자 준비 상태·Better Auth 설정·독립 인증 팩터리.
- tests/: 실제 SQLite와 Web Request를 이용하는 서버 통합 검증.

.env.local, 실제 데이터베이스·이미지, 비밀값과 node_modules는 배포 소스 압축본에 포함하지 않습니다.
