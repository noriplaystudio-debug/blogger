# 프로젝트 변경 이력

## 2026-10-22 KST · v5.2.0 · 무료 나눔의 금액 의견 수집

- 요청: 무료 나눔에서 적절하다고 생각하는 금액을 받고, 모인 정보로 향후 권장 상한액을 검토한다.
- 구현: 열람·추가 사용료의 가정 의견, 참여자 판단 완성도·선택 사유, 공개/통계 이용 안내; 계정당 현재 의견 1개, 수정·철회, 작성자·운영자 참여 차단, 익명 공개, 운영 제외·복구.
- 수집: 자료 내용·질문 버전, 당시 분류·이용 조건·역할을 보존하고 금액 수정 이벤트를 기록한다. 비공개·다른 자료 버전·철회·운영 제외를 현재 집계에서 뺀다.
- 분석: 분야·완성도·이용 조건/버전·기간·역할별 중앙값과 분포, 글별 중앙값에 같은 비중을 주는 검토 값과 표본·작성자 집중 조건. CSV·JSON은 익명 집계만 제공한다. 현재 권장액과 가격 자유 정책은 유지한다.
- 변경: server/valuations.mjs, valuation-data.mjs, sharing.mjs, api.mjs, operations.sql; public/assets/valuation-policy.js, valuations.js, valuations.css 및 화면 연결; db/schema.ts; tests/valuations.test.mjs와 17단계 브라우저 검사; 미리보기·운영/검증 문서.
- 검증: 57개 모듈 소스 검사와 8개 검사 묶음 통과. 20,001개 표본에서 일부만으로 기준을 계산하지 않는지도 확인했다. 실제 브라우저 doctor는 실행 파일 부재와 서버 자식 프로세스 종료로 blocked, UI 통과 0.
- 배포: 로컬 소스 반영. 실제 빌드·D1 마이그레이션·원격 게시 미완료. 상세 증거는 VALIDATION.md 및 VALIDATION_V5_2.json을 따른다.


## 2026-10-22 KST · v5.1.0 · 권장 가격과 무료 나눔

- 요청: 품질에 따른 가격 기준을 등록·구매 전에 안내하되 권장 상한을 강제하지 않는다. 무료 아이디어 나눔터를 함께 구현한다.
- 구현: 수준별 자료 기준·분야 예시·두 권장 가격·초과 차액을 공통 모듈로 계산한다. 판매가/수수료를 바꾸지 않고 참고 기준을 신규 주문에 저장한다. 초기 참고액과 판매자 선택 수준임을 표시한다.
- 나눔: 무료 본문·이용 조건, 공개 전 검토, 내 글·수정·응답 유실 조회·숨김, 운영자 검토와 검색·페이지를 구현한다. 기존 유료 자료 접근 경로와 분리한다.
- 검사 중 발견: 기존 운영 라우터가 새 나눔 관리 경로보다 먼저 모든 관리자 요청을 처리해 404를 반환했다. 라우팅 순서를 수정하고 통합 검사로 확인했다.
- 주요 변경: public/assets/pricing.js, sharing.js, sharing-policy.js, pricing-sharing.css; server/api.mjs, sharing.mjs, operations.sql; db/schema.ts; 판매·상세·결제·거래 기록·운영 화면; ui/index.html; tests/pricing-sharing.test.mjs와 브라우저 시나리오; 미리보기 및 운영 문서.
- 배포: 로컬 소스 수정. 호스팅 프로젝트 식별 불일치와 배포 도우미 부재 상태이며 원격 게시하지 않음. GitHub 브랜치의 기존 수동 등록 파일은 v5.0.4 소스이므로 새 기능 검증에는 새 스냅샷이 필요함.
- 실제 검사 결과와 남은 제한은 VALIDATION.md를 기준으로 확인한다. 브라우저 미실행을 통과로 기록하지 않는다.
