# 무료 나눔 가격 의견과 가격 기준 참고 통계 · v5.2

2026-10-22 KST. 요청: 무료 나눔터에서 적절하다고 생각하는 금액을 의견으로 받고, 이를 보관·집계해 향후 권장 상한액을 검토할 자료로 사용한다.

## 참여 흐름

나눔 원문 → 금액 의견 남기기 → 참여자가 판단한 완성도 선택 → 열람료·추가 독점 사용료 중 하나 이상 입력 → 선택 사유와 공개·통계 이용 안내 확인 → 저장.

같은 분량·완성도의 기획을 유료 상품으로 검토한다는 가정이다. 무료 나눔 글의 공개와 이용 허락은 그대로이며, 결제·구매 제안·독점권 이전은 발생하지 않는다. 가격 의견은 실제 거래 가격이나 구매 의사 확약으로 표시하지 않는다.

- 금액은 KRW 정수 0~100,000,000원. 빈칸은 의견 없음, 0원은 무료가 적절하다는 의견이다. 두 금액을 강제로 같게 하거나 사용료를 더 높게 만들지 않는다.
- 완성도는 참여자가 자료를 보고 판단한 `아이디어 / 구체화 기획 / 전문 기획`이다. 객관적인 품질 인증으로 취급하지 않는다.
- 사유는 선택, 최대 1,000자다. 금액·완성도·사유는 이름과 회원 ID 없이 공개됨을 알린다.
- 새 작성창에는 가격·기획 수준을 미리 채우지 않는다. 다른 사람의 집계 결과는 별도의 화면에서 본다. 현재 평가 대상 원문도 펼쳐 다시 읽을 수 있다.
- 가입한 판매자·구매자 모두 다른 사람의 공개 글에 참여할 수 있다. 작성자 본인과 운영자 계정은 참여하지 못한다.
- 계정·자료 내용·질문 버전당 현재 의견 1개만 반영한다. 수정·중복 제출·응답 유실 재시도가 표 수를 늘리지 않는다. 최근 24시간 신규 의견은 최대 100개다.
- `내 금액 의견`에서 수정·철회와 집계 상태를 확인한다. 글이 숨겨진 뒤에도 본인 의견을 철회할 수 있다. 작성 동의는 임시 작성본에 저장하거나 자동 체크하지 않는다.

## 공개 결과

글별로 참여 계정 수, 각 가격 종류의 의견 수·중앙값·가운데 50% 범위·무료 의견 수와 금액대별 분포를 제공한다. 두 금액 중 하나만 입력하면 그 항목에만 포함한다. 공개 사유는 페이지로 나누어 보여주며, 5개 계정 미만이면 표본이 적음을 표시한다.

중앙값·분위수는 정렬한 값 사이를 선형 보간하며 소수 둘째 자리까지 표현한다. 통계 수치이므로 결제 금액을 뜻하지 않는다. 극단적으로 높거나 낮은 값도 자동 삭제하지 않으며 운영 통계에서 IQR 기준 참고 개수만 표시한다.

## 운영 통계와 추후 상한액 검토

나눔터의 운영자 전용 `가격 기준 참고 통계`에서 종류, 참여자 판단 완성도, 이용 허락 조건, 참여 역할, 최근 30·90·365일/전체 기간을 선택한다. API는 세부 유형 필터도 제공한다. 기본 기간은 최근 90일이며 참여자가 마지막으로 금액 의견을 저장한 시각을 사용한다. 운영 제외·복구가 의견의 신선도를 높이지 않는다.

분야·완성도·이용 조건과 그 문구 버전을 구분한다. 무료 열람만 허용한 자료와 이미 비독점 상업 활용을 허용한 자료를 같은 그룹으로 섞지 않는다. CSV·JSON은 이 분류·기간·통화·질문 버전과 익명 집계만 포함하고 회원 ID·개별 의견 사유·이름은 포함하지 않는다.

검토용 가격 수치는 아래 초기 운영 조건을 모두 충족할 때만 표시한다. 이는 통계적 신뢰를 보증하는 기준이 아니다.

1. 같은 그룹에서 글마다 해당 금액 종류의 의견이 5개 이상이어야 한다.
2. 그런 글이 5개 이상, 해당 글들에 참여한 계정이 20개 이상, 글 작성자가 3개 계정 이상이어야 한다.
3. 한 작성자의 글이 대상 글의 40%를 넘지 않아야 한다.
4. 각 글의 중앙값에 같은 비중을 주고, 그 중앙값들의 75백분위 값을 검토용 수치로 제시한다. 표 수가 많은 한 글이 그대로 전체 통계를 지배하지 않도록 한다.

조건이 부족하면 값을 만들어 내지 않고 `표본 조건 부족`으로 표시한다. 현재 권장액은 비교용으로 함께 보며 **자동으로 변경하지 않는다**. 과도한 금액만으로 판매·구매를 차단하지 않는 v5.1 정책도 유지된다.

무료 공개 자료의 자발적·가정적 의견에는 참여자 선택과 게시 유지 편향이 있다. 계정 수를 검증된 실제 사람 수로 표현하지 않는다. 향후 실제 유료 거래의 전환·자료 일치도·환불 사유·만족도 및 분야 검토와 함께 판단해야 한다. 의견의 최고가·단순 평균·가상 미리보기 표본을 곧바로 새 상한액으로 사용하지 않는다.

## 자료 보존과 집계 경계

- `share_value_sources`: 현재 자료 내용의 해시와 버전.
- `share_value_opinions`: 금액·완성도·사유, 참여 역할, 원문 종류·유형·이용 조건의 당시 내용·버전, 질문 버전, 수정·철회·운영 제외 상태.
- 자료가 수정되면 현재 내용의 해시를 갱신한다. 이전 내용에 대한 의견은 보존하되 새 자료 통계와 섞지 않는다. 다른 질문 버전도 합치지 않는다.
- 공개 중인 현재 자료의 활성 의견만 집계하며 철회·운영 제외·숨김 글은 빠진다. 운영 제외를 해제해도 참여자가 철회한 의견을 다시 활성화하지 않는다.
- 금액 수정은 현재 행을 갱신하고, 당시 금액·완성도·역할·자료 버전을 변경 이벤트에 남긴다. 공개·기준 통계에는 최신 행만 사용한다. 철회를 데이터 영구 삭제와 같은 기능으로 안내하지 않는다.
- 운영자는 원본 의견의 제외·복구 사유를 기록한다. 금액의 높고 낮음만으로 제외하지 않도록 안내하며, 글 작성자에게 다른 사람의 의견을 지우는 권한을 주지 않는다.
- 조회 범위가 20,000개 의견을 넘으면 기간·분야를 좁히도록 오류를 반환한다. 일부 자료만 조용히 잘라 기준을 계산하지 않는다.

로컬 SQLite 초기화는 새 테이블·인덱스를 추가하며 기존 아이디어·가격·주문을 바꾸지 않는다. 배포용 Drizzle 선언도 추가했다. 실제 D1 마이그레이션·프레임워크 빌드·배포는 별도로 필요하다.

## 검증

`tests/valuations.test.mjs`는 실제 SQLite·Web Request로 인증·작성자 격리·동시 중복·수정·철회·운영 검토·내용 버전·기간/역할 필터·익명 내보내기·권장액 불변·대량 집계 제한을 검사한다. 순수 통계 검사에서 극단값·빈칸/0·글별 비중·표본 및 작성자 집중 조건을 확인한다. 화면 템플릿의 입력 이스케이프·동의 미체크·가격 미리 채우기 방지와 가입 후 복귀도 검사한다.

브라우저 시나리오에는 금액 의견 저장·수정/한 표, 모바일 작성창, 운영 통계·CSV·의견 제외, 본인 철회를 추가했다. 전체 시나리오는 17단계이며 실제 브라우저 실행 없이 통과했다고 표시하지 않는다. 정적 미리보기의 통계와 참여 수는 디자인 확인용 가상 표본임을 화면 안에 명시한다.
