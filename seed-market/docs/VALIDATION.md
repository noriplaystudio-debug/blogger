## 아직 검증하지 않은 항목

- 실제 공급자 키를 이용한 네이버·카카오·구글 OAuth와 인증 메일 도착.
- 의존성 설치, Better Auth DB 마이그레이션 실행, Vinext 빌드와 배포용 Drizzle 마이그레이션 생성.
- 브라우저의 모바일·데스크톱 화면, 키보드 조작 및 전체 가입·구매 흐름.
- 실제 PG 결제·환불·웹훅·송금과 판매자 본인확인·세무 처리.
- 외부 서버 배포, HTTPS 도메인, 영속 저장소 및 백업·복원.

이전 작업의 패키지 설치가 네트워크 제한으로 완료되지 않았으며 이번 작업에서도 의존성 설치·빌드·마이그레이션은 진행하지 못했습니다.
이 결과를 실제 결제 가능 또는 출시 완료로 해석하면 안 됩니다.
이번 작업에서 `listen EPERM: operation not permitted 127.0.0.1:4173`을 다시 확인했습니다. Playwright의 Chromium 실행도 중단되어 브라우저 직접 조작은 미검증입니다.
공식 Sites 동기화·게시 도우미도 실행 환경에 없어 소스 커밋·호스팅 배포는 하지 못했습니다.
정적 디자인 미리보기는 실제 브라우저 검증을 대체하지 않습니다.
