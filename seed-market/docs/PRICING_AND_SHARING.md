# 가격 안내와 무료 나눔터 · v5.1

2026-10-22 KST · 사용자 결정: 상한액은 등록·구매 시 안내만 하며, 판매가를 강제로 맞추거나 초과 등록·구매를 차단하지 않는다.

## 권장 상한액

| 판매자가 선택한 수준 | 열람료 권장 상한 | 추가 독점 사용료 참고 상한 | 자료 기준 |
| --- | ---: | ---: | --- |
| 아이디어 | 3,000원 | 30,000원 | 대상·문제/창작 의도, 핵심 제안과 기존 사례와의 차이 |
| 구체화 기획 | 10,000원 | 100,000원 | 실행 단계·자원, 구체적인 제공 자료와 제외 범위 |
| 전문 기획 | 30,000원 | 300,000원 | 실험·제작·조사 근거, 비용·일정의 가정과 미검증 부분 |

초기 운영 가설이며 거래 통계나 개별 감정 결과가 아니다. 사용료는 열람료 권장액의 10배를 초기 참고액으로 사용한다. 분야별로 다른 자료 예시를 제공하지만 카테고리만으로 자동 가산하지 않는다. 음악·공연에 사업 분야의 고객 조사만 요구하는 등의 일괄 평가는 하지 않는다.

현재 수준은 판매자가 선택한다. 문장 길이·이미지 개수로 점수를 매기거나 AI가 품질을 검증했다고 표시하지 않는다. 운영자는 자료·출처·제공 범위와 선택한 수준의 일치 여부를 검토한다. 높은 가격만으로 반려하지 않는다. 근거가 부족하거나 설명이 다르면 자료 보완·수준 변경을 요청한다.

권장액은 판매 작업실의 가격 단계·최종 확인, 공개 카드·상세, 열람권·사용권 결제, 운영 심사에 표시된다. 초과 시 종류별 차액과 재확인 안내를 표시한다. 가격 자동 인하, 제출 금지, 추가 필수 면책 동의는 없다. 권장 상한액을 입력하는 버튼은 선택 기능이며 입력 뒤에도 가격을 수정할 수 있다.

가격 입력의 기존 기술적 범위(1,000~100,000,000원, 1,000원 단위)와 사용료≥열람료 조건은 유지된다. 무료 등록은 별도 나눔터에서 한다. 열람료와 추가 사용료는 기존 계약대로 별도이며 자동 차감하지 않는다. 권장 가격 기능이 기존 주문·수수료·환불 조건을 바꾸지 않는다.

서버가 공개 정보와 권장액을 생성한다. 클라이언트가 보낸 권장액은 가격·수수료 계산에 사용하지 않는다. 신규 주문의 참고 기준·버전·당시 판매가를 주문 트랜잭션에 저장하고 거래 기록에 표시한다. 과거 주문에 새 기준을 소급 기록하지 않으며, 이 기록은 구매자가 안내를 읽었다는 별도 동의 증명이 아니다. 환불 권리를 포기시키는 문구로 사용하지 않는다.

향후 실제 거래가 쌓이면 분야·수준별 구매 전환, 환불 사유, 설명 일치도와 만족도를 함께 보고 기준 버전을 조정한다. 현재 자동 시세 산정·전문가 인증·검증 실적은 제공하지 않는다.

## 무료 나눔터

`/#sharing`, 개별 원문 `/#share/<id>`. 판매자·구매자 모두 가입 후 작성하며 승인된 본문은 비회원도 무료로 읽는다. 기존 유료 상세와 별도 테이블·API로 관리한다. 나눔 글 읽기로 주문이나 열람권은 생성되지 않는다.

- 종류·세부 유형, 제목·요약·본문과 이용 조건을 입력한다.
- 무료 열람만 허용하거나, 출처 표시 후 비독점 복제·수정·배포·상업적 활용을 허용한다. 독점권 이전은 포함하지 않는다.
- 작성·이용 허락 권한과 전체 무료 공개를 확인한 뒤 검토 요청한다. 동의 버전과 당시 이용 문구를 저장한다.
- 검토 대기 → 승인 공개 / 보완 요청. 운영자는 공개 중단도 가능하며 변경 사유·버전을 기록한다.
- 내 글 목록, 계정별 탭 내 작성본, 대기·보완 글 수정과 재검토, 응답 유실 조회·등록 재시도를 지원한다.
- 공개 글은 본문·이용 조건을 조용히 바꾸지 않는다. 작성자가 숨기면 원문·목록에서 제외하고, 운영자가 다시 공개하지 못하게 한다. 이미 허용한 이용을 숨김으로 소급 취소한다고 안내하지 않는다.
- 공개 글은 종류·제목/요약 검색과 페이지 이동을 제공한다. 검토 대기·보완 사유는 작성자·운영자 외에 제공하지 않는다.
- 계정당 대기 글 10개, 길이·종류·유형·이용 조건 검사, 작성자 격리, 운영자 권한과 오래된 버전 처리 방지를 적용한다.

유료 상품의 공개 소개에서 이미 무료 공개한 부분과 추가 제공하는 자료를 구분하도록 운영한다. 나눔 활동이나 인기만으로 유료 상품의 검증 등급을 올리지 않는다.

## 검증 및 배포 범위

`npm test`에 실제 SQLite·Web Request 기반 가격/나눔 통합 검사를 추가했다. 권장액 초과 등록·열람·사용 구매, 원래 가격/수수료, 주문 참고 기록, 공개 전 차단·운영 심사·작성자 수정·숨김·권한·검색·수량·중복 요청·입력 이스케이프를 검사한다.

브라우저 시나리오는 초과 가격 안내와 무료 나눔 3단계를 포함하는 총 14단계로 확장했다. 실행 증거 없이 통과로 표시하지 않는다. 정적 미리보기에는 창작 샘플과 가상 거래를 명시한다.

로컬 SQLite는 기존 데이터를 지우지 않고 `order_price_guidance`, `shared_ideas` 테이블과 인덱스를 생성한다. 배포용 Drizzle 선언도 추가했으나 실제 D1 마이그레이션·프레임워크 빌드·원격 배포는 별도로 필요하다. 현재 호스팅 ID의 원격 메타데이터는 아이디어 마켓과 다른 계산기 프로젝트이며 배포 버전은 0이다. 이를 아이디어 마켓의 확인된 운영 배포로 취급하거나 덮어쓰지 않았다.
