# seed v3 — 탐색과 판매 등록 개선 기록

이 문서는 v3의 변경 기록입니다. 현재 종류·세부 유형·관련 분야는 [v4 분류 기준](CATEGORY_POLICY.md)을 따릅니다.

배너 → 분야 탐색 → 검색·비교 → 판매 등록의 흐름을 개선했습니다.
거래·수수료·운영 검토 기능은 유지하며 실제 결제 없는 테스트 상태입니다.

## 배너와 첫 화면

- seed의 초록색과 종이·씨앗 모티프를 유지한 전용 SVG 일러스트를 추가했습니다.
- ‘새로운 발견’, ‘더 깊은 기획’, ‘나의 아이디어’ 세 가지 배너를 직접 선택합니다. 자동 회전은 없습니다.
- 각 버튼은 전체 탐색, 전문 기획 필터, 판매 등록으로 연결됩니다.
- 무료 요약 → 유료 열람 → 별도 사용권의 거래 단계를 배너 아래에서 안내합니다.
- 분야별 카드는 설명과 대표 주제를 제공해 검색어가 없어도 탐색을 시작할 수 있습니다.

## 분야와 세부 주제

대분류 5개에 세부 주제 25개를 연결했습니다. 각 분야의 마지막 항목은 기타 분류입니다.

| 분야 | 세부 주제 |
| --- | --- |
| 테크 · AI | AI·자동화, 업무·생산성, 앱·플랫폼, 데이터·분석, 그 밖의 기술 |
| 라이프스타일 | 로컬·여행, 취미·생활, 건강·돌봄, 환경·지속가능성, 그 밖의 라이프 |
| 비즈니스 | 매장·소상공인, B2B·기업 서비스, 구독·멤버십, 순환 비즈니스, 그 밖의 비즈니스 |
| 콘텐츠 · 디자인 | 디자인·브랜딩, 출판·글쓰기, 영상·오디오, 크리에이터 도구, 그 밖의 콘텐츠 |
| 소셜 · 커뮤니티 | 교육·재능 교환, 취향 커뮤니티, 로컬 연결, 사회적 가치, 그 밖의 연결 |

신규 등록에는 분야에 맞는 세부 주제를 요구하고 서버에서 조합을 검사합니다.
기존 등록글에 세부 주제가 없으면 공개 제목·요약·태그의 키워드로 분류하며, 근거가 없으면 해당 분야의 기타 항목으로 표시합니다.
기존 상세 자료나 주문 조건을 변경하는 백필은 하지 않습니다.

## 검색과 필터

검색은 서버의 `/api/discovery`에서 처리하고 페이지별 결과를 돌려줍니다.
이전 목록 API의 최신 300개 제한에 의존하지 않습니다.

- 제목 일치를 우선하고 태그·공개 요약·분류의 일치도를 함께 평가합니다.
- 영문 대소문자, 전각 영문, 띄어쓰기 차이를 정규화합니다.
- ‘인공지능/AI’, ‘로컬/동네/지역’ 등 지정한 동의어와 두 글자 이상의 한글 초성을 지원합니다.
- 예: `회의메모`, `인공지능`, `ㄱㄹ ㄹㅌ`로 샘플 아이디어를 찾습니다.
- 분야, 세부 주제, 기획 수준, 판매 상태, 최소·최대 가격을 조합합니다.
- 가격 필터와 가격순 정렬은 열람료·독점 사용료 중 선택한 기준을 사용합니다.
- 판매 중을 기본으로 보여주며 판매완료를 포함하거나 따로 볼 수 있습니다.
- 검색 제안은 현재 필터에 맞는 판매 중 아이디어의 공개 제목·태그에서만 만듭니다.
- 적용 조건은 개별 칩으로 해제하며, 검색어만 유지하고 조건을 넓히는 빈 결과 안내를 제공합니다.
- URL에 조건과 페이지를 기록해 새로고침·주소 전달·뒤로가기를 지원하도록 연결했습니다.

검토 대기·반려·게시 중단 글, 유료 본문, 비공개 이미지, 심사 사유는 검색·제안·분류 집계에 넣지 않습니다.
분류 옆 수량은 다른 필터를 적용한 상태에서 해당 분류로 이동할 때의 결과 수입니다.

현재 엔진은 공개 메타데이터를 읽고 서버에서 일치도와 필터를 계산하는 초기 규모용 구현입니다.
별도 검색 서비스나 의미 기반 AI 검색을 연결한 상태는 아닙니다. 등록량이 커지면 FTS 인덱스와 부하 검증이 필요합니다.

## 아이디어 비교

최대 3개를 담아 공개 요약, 분야·주제, 기획 수준, 열람료, 별도 사용료, 판매 상태를 같은 표에서 비교합니다.
비교 화면을 열 때 서버에서 상태를 다시 확인하며, 열 수 없는 등록글은 제외합니다.
담기는 예약이나 사용권 취득이 아닙니다. 구매 권한과 단일 독점 구매자는 기존 거래 API가 결정합니다.

## 네 단계 판매 작업실

| 단계 | 작성·확인 내용 |
| --- | --- |
| 1. 공개 소개 | 제목, 분야·주제, 기획 수준, 공개 요약, 태그, 선택적 커버 |
| 2. 상세 자료 | 문제·해결·대상·실행 계획, 제공 자료 이름, 상세 이미지, 창작 근거·검증·위험 |
| 3. 가격·조건 | 별도 열람료와 사용료, 가격 예시의 명시적 적용, 수수료 차감 예상액 |
| 4. 최종 확인 | 구매자에게 보일 공개 소개, 자료 공개 범위, 수수료·정산 및 판매 권한 동의 |

단계가 바뀌어도 같은 양식과 입력값을 유지합니다.
필수 입력과 글자 수, 태그·자료 개수, 분야·주제 조합, 가격 관계와 이미지 수량을 확인합니다.
서버도 별도로 검사하므로 화면 단계를 건너뛰어 권한이나 조건을 우회할 수 없습니다.
긴 한글 기획서가 화면의 최대 입력 범위 안에서 등록되도록 JSON 요청 상한을 160KB로 조정했습니다.

기획 수준을 바꿨다고 작성한 가격을 덮어쓰지 않습니다. 가격 예시는 버튼을 눌러야 적용합니다.
예상액은 원 단위 내림 수수료를 차감한 금액이며, 실제 PG 비용·세금 차감 전입니다.
정책이 바뀌면 새 조건을 확인하고 다시 동의하며 작성한 글과 이미지는 유지합니다.

이미지는 끌어 놓기·여러 번 추가·개별 제거와 미리보기를 제공합니다.
무료 커버와 결제 후 이미지를 다른 영역과 표시로 구분합니다.
실제 업로드는 제출 시 수행하고, 취소·다른 이미지로 재시도할 때 미사용 업로드를 정리합니다.

## 임시저장과 개인정보

- 같은 탭에서 창을 닫았다 다시 열면 작성 내용과 선택 파일을 메모리에서 이어갑니다.
- ‘이 기기에 임시저장’을 선택하면 글만 현재 브라우저에 저장하고 이후 변경도 저장합니다.
- 저장본은 내부 회원 ID별로 구분하며, 다른 계정의 저장본은 불러오지 않습니다.
- 이미지 파일과 계약 동의는 기기 저장본에 포함하지 않습니다. 새로고침 후 이미지를 다시 첨부하고 새로 동의해야 합니다.
- 저장본을 불러올 때 남아 있던 파일을 비워 다른 작성본의 이미지가 섞이지 않게 합니다.
- 저장본 삭제는 현재 양식의 입력을 지우지 않으며, 등록 성공 시 해당 저장본을 정리합니다.

기기 임시저장은 서버 보관이나 암호화 저장을 뜻하지 않습니다.
회원의 서버 주문·권리 기록은 기기 저장 내용과 별개입니다.

## 작은 사용성 개선

모바일 상세 필터 접기, 검색 제안 키보드 조작, 한글 조합 중 검색 방지,
로딩·빈 결과·연결 오류의 구분, 재시도, 글자 수·작성 준비도,
긴 제목 말줄임과 반응형 비교 표, 모션 줄이기 설정 대응을 추가했습니다.
검색 취소와 요청 순서 검사를 넣어 이전 응답이 최신 결과를 덮어쓰지 않게 했습니다.
페이지를 이동해도 찜한 글의 요약은 계정에서 별도로 조회합니다.

## 디자인 미리보기와 검증 범위

`node scripts/design-preview.mjs /원하는/절대경로/preview.html`로 외부 자원 없는 HTML 미리보기를 만듭니다.
홈 화면과 판매 작업실의 각 단계 모양을 볼 수 있으며 검색·인증·결제·등록 API는 연결하지 않습니다.
미리보기 상단에 이 제한과 샘플임을 표시합니다. 실제 기능 검증 결과와 구분하세요.

`npm run check`, `npm test` 및 생성 HTML의 구조 검사는 통과했습니다.
실제 브라우저·모바일 화면과 전체 조작은 로컬 포트의 EPERM 오류로 확인하지 못했습니다.
SDK 설치·빌드·배포와 실제 OAuth·PG 연결도 아직 완료하지 않았습니다.
구체적인 결과는 [검증 기록](VALIDATION.md)을 참고하세요.

Sites 소스 동기화·게시 도우미가 현재 작업 환경에 없으므로 저장된 호스팅 프로젝트의 새 버전을 게시하지 못했습니다.
기존 프로젝트 ID와 접근 범위는 유지하며 새 프로젝트를 만들지 않았습니다.
